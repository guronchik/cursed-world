# Свои обои

Положи сюда картинки (`.jpg`, `.png`, `.webp`, `.avif`, `.svg`) — они сами появятся в
**Settings → Внешний вид → Обои** после перезапуска `npm run dev` (в dev-режиме — сразу после обновления страницы).

Рекомендации: 1920–2560 px по длинной стороне, webp/jpg до ~600 КБ.
Официальный арт аниме сюда лучше не класть, если сайт публичный.
